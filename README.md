# jotunlegion.github.io

Portfolio site for **Dmytro Bondar** — Senior Game Designer (AI-first prototyping & LiveOps).

Live at <https://jotunlegion.github.io>

## Pages

| Page | What it holds |
|---|---|
| `index.html` | Resume: positioning, working method, experience timeline, skills, education |
| `work.html` | 12 shipped titles with store screenshots, descriptions and filters |
| `lab.html` | 6 playable prototypes with captured screenshots and live links |

## How it is built

Plain HTML, CSS and JavaScript — no framework, no build toolchain, no tracking.
The three pages are generated by `build.py`, which holds all project copy in one
place so the markup stays consistent:

```bash
python build.py        # requires Pillow, used only to read image orientation
```

Screenshots under `assets/img/projects/` were pulled from the live App Store,
Google Play, Big Fish Games and itch.io pages. Screenshots under
`assets/img/prototypes/` were captured from the running builds.
